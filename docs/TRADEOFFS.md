# Trade-offs and deviations

This file records (1) the key trade-offs behind the design and (2) every place where the build
deviates from, or fills a gap in, `docs/SPEC.md`. The SPEC itself is never edited.

## Deviations and gap-filling decisions made during the build

| #   | Topic              | Decision                                                                                                                                                                 | Why                                                                                                                                                                                                                                                                 |
| --- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D1  | TypeScript version | Pinned to TypeScript **6.0.x**, not the newest 7.0.                                                                                                                      | `typescript-eslint` (required by SPEC §1) supports TypeScript `<6.1.0` only. Lint is a CI gate, so the compiler follows the linter.                                                                                                                                 |
| D2  | Local DB port      | docker compose publishes Postgres on host port **5434** (overridable with `ACME_DB_PORT`).                                                                               | 5432 and 5433 are commonly taken by other local Postgres instances; a fixed non-default port keeps `docker compose up` working out of the box.                                                                                                                      |
| D3  | Local env loading  | `pnpm dev`, `db:migrate` and `db:seed` load `apps/api/.env.example` and then `apps/api/.env` via Node's `--env-file-if-exists`. `pnpm start` (production) loads no file. | Makes the SPEC §13.1 command (`docker compose up -d && pnpm install && pnpm db:migrate && pnpm db:seed && pnpm dev`) work with no copy step. The example file holds only local-only values; production must set real env vars, and env validation still fails fast. |
